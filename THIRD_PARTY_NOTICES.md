## Optional sources and tools

- [FalkorDB GraphRAG-SDK](https://github.com/FalkorDB/GraphRAG-SDK) is Apache-2.0 and is an optional dependency for provider-backed ingestion. Its installation or presence does not mean document extraction has run.
- [Graphify](https://github.com/Graphify-Labs/graphify) is an optional source of imported project graphs. It is Apache-2.0 with retained MIT notices for older contributions. Relay's import adapter preserves provenance; it does not vendor Graphify's implementation.
- TypeScript, Vite, pytest, Ruff, and other development/transitive packages keep their own licenses as shipped. Consult installed package license files and the lockfiles for the complete resolved dependency set.

The Meridian company names, sample documents, graph schema, Ripple rules, and application workflow are Relay demo content. No upstream example dataset is represented as private company data.
